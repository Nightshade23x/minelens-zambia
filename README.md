# MineLens Zambia

MineLens Zambia is a mining intelligence and information retrieval platform
focused on public Zambian mining information.

## Initial Goals

1. Download official mining documents
2. Extract text from PDF and HTML sources
3. Split documents into searchable chunks
4. Implement keyword search
5. Implement semantic/vector search
6. Add source-aware answers
7. Add GIS and recommender functionality later

## Current Stage

Phase 1: Document ingestion and information retrieval.
